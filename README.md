# CLASS STUDENT INFORMATION

- **Name:** Su Man
- **Student ID:** 202300232


This project displays three students' names, IDs, departments, and welcome messages in the browser console. It also prints the total number of students.

The page uses Tailwind CDN utilities `bg-slate-900` for the background and `font-sans`, `text-4xl`, `font-bold`, `tracking-wide`, `text-white`, `text-lg`, `leading-relaxed`, and `text-slate-200` for typography.

To run it, open `index.html` in a browser (or with VS Code Live Server), then open the browser developer console.
